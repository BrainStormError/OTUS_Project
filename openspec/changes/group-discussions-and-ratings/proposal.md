# Group Discussions and Ratings

## Why

Группа сейчас — это список участников и нулевая статистика: в ней нельзя ничего обсуждать и нельзя ставить общие оценки. Добавляем форум группы, групповые оценки фильмов/сериалов и ленту активности группы — ядро социального сценария проекта.

## What Changes

- Страница группы перестраивается в табы: Обсуждения | Оценки | Активность | Участники | Статистика.
- Обсуждения (форум): темы создает только администратор группы (защита от спама), комментарии оставляют все участники. Отдельная вкладка со списком тем; внутри темы — список комментариев.
- Групповые оценки: каждый участник оценивает фильм/сериал тем же UX, что «Мои фильмы»/«Мои сериалы» (0–10, шаг 0.1, комментарий, дата). Отдельная вкладка — список оценок группы; групповая оценка фильма — среднее по оценкам участников (вычисляется на чтении, не хранится).
- Прикрепление обсуждения: администратор может прикрепить обсуждение к групповой оценке (оцениваемому фильму/сериалу). Одна групповая оценка — одно обсуждение; внутри — много комментариев.
- Активность группы: вкладка с последними событиями группы — создание обсуждений, комментарии, групповые оценки, вступления. У события оценки, к которой прикреплено обсуждение, есть кнопка перехода к обсуждению.

## Capabilities

### New Capabilities

- `groups/discussions`: форум группы — темы (только админ), комментарии (все участники), вкладка «Обсуждения».
- `groups/ratings`: групповые оценки — выставление участниками, средняя оценка группы, вкладка «Оценки», прикрепление администратором одного обсуждения к оцененному медиа.
- `groups/activity`: лента активности группы — события обсуждений, комментариев, оценок и вступлений, кнопка перехода к обсуждению из события.

### Modified Capabilities

- `ui/screens`: требование «Groups and admin panel» — страница группы строится из табов Обсуждения / Оценки / Активность / Участники / Статистика.

## Impact

- Новые миграции: `group_discussions` (с необязательной ссылкой на медиа и частичным уникальным индексом «одно обсуждение на медиа группы»), `discussion_posts`, `group_ratings` (уникальность группа+участник+медиа).
- Новый модуль `src/modules/discussions`; расширение `src/modules/groups` (оценки — в рамках группового контекста) — либо отдельный модуль, решается в design.
- Новые route handlers: темы, комментарии, групповые оценки, прикрепление обсуждения.
- `activity_events` — пишутся события с `group_id` (`post_created`, `comment_created`, `film_rated`/`series_rated` в контексте группы); новый групповой запрос ленты (фильтр по группе + проверка участника).
- Страница `/groups/[id]` и компоненты `features/movie-tracker` — таб-навигация, переиспользование `RatingForm`/модалок.
- Кнопка «К обсуждению» — ссылка достается на чтении по связи медиа→обсуждение, не хранится в payload события.
- Тесты: unit (политики ролей, схемы, среднее), integration (репозитории, уникальность, лента группы), e2e (оценить → создать обсуждение → увидеть в активности).
