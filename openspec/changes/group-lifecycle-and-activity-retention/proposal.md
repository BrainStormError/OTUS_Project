## Why

Управление составом группы неполное: рядовой участник не может выйти из группы, администратор не может корректно покинуть её (самоисключение либо запрещено для последнего админа, либо допустимо при наличии второго), а способа распустить группу нет вовсе. Приглашение не даёт обратной связи и допускает повторную отправку. Лента активности не ограничена по времени и копится бесконечно, а список активности в профиле не ограничен периодом.

## What Changes

- **Выход из группы.** Рядовой участник может покинуть группу; после выхода он теряет доступ к содержимому закрытой группы.
- **Запрет самоисключения.** Администратор не может удалить себя из состава группы — ни через панель участников, ни через API.
- **Роспуск группы.** Администратор может распустить группу; группа и все связанные данные (участники, приглашения, оценки, обсуждения и их посты) удаляются, а события активности этой группы удаляются явно.
- **Обратная связь по приглашению.** После отправки приглашения действие становится «Отправлено» и неактивно; повторная заявка тому же пользователю невозможна.
- **Хранение активности.** События ленты на главной старше одних суток удаляются (без отдельного планировщика). Список активности в профиле показывает только записи за последнюю неделю, не удаляя сами оценки.

### Modified Capabilities

- `groups/management`: добавляются выход рядового участника, запрет самоисключения администратора и роспуск группы.
- `ui/screens`: админ-панель получает состояние «Отправлено», действие выхода и «Распустить группу»; профиль ограничивает список активности последней неделей.
- `activity/feed`: лента хранит и показывает только события за последние сутки.

## Impact

- **Код:** `src/modules/groups` (`service.ts`, `repository.ts`, `schema.ts`, `index.ts`), `src/core/auth/policy.ts` (экшены `group:leave`, `group:delete`), `src/app/api/groups/...` (выход, роспуск), `src/modules/activity/repository.ts` (ленивое удаление устаревших событий при чтении), `src/modules/profiles/service.ts` (недельный фильтр `recent`), `src/components/features/movie-tracker/AdminMemberPanel.tsx`, `GroupSettingsForm.tsx`, `ProfileView.tsx`.
- **БД:** без новых таблиц — роспуск использует существующие каскады плюс явное удаление `activity_events` группы.
- **Тесты:** unit `policy`/схем, integration на выход, роспуск, запрет самоисключения и хранение активности, unit UI для состояний кнопок.
- **Поведение:** дневной отсев событий глобальный, поэтому вкладка «Активность» группы также показывает только последние сутки.
