## Why

Переключение вкладок на странице группы выполняется полной серверной навигацией: пока грузятся данные вкладки, интерфейс «замирает» без обратной связи, и вся страница перерисовывается заново.

## What Changes

- **Оболочка страницы группы остаётся на месте.** Шапка группы и панель вкладок не перерисовываются при переключении; меняется только содержимое активной вкладки.
- **Скелет загрузки по форме вкладки.** Пока данные вкладки грузятся, показывается placeholder, соответствующий ожидаемому содержимому (обсуждения, оценки, активность, участники, статистика) вместо пустого экрана.
- **Серверный стриминг.** Данные каждой вкладки грузятся в отдельном асинхронном компоненте и подставляются после готовности без полной перезагрузки страницы.
- Ссылки, deep-links и проверка доступа к группе сохраняются.

## Capabilities

### New Capabilities

- Нет. Изменение правит поведение существующей возможности (состояния интерфейса и экран группы).

### Modified Capabilities

- `ui/interface-states`: загрузка вкладок группы описывается как skeleton по форме содержимого вкладки, подставляемый без полной перезагрузки; шапка и панель вкладок при этом остаются видимыми.

## Impact

- **Код:** `src/app/(app)/groups/[id]/page.tsx`, новые компоненты панели/скелета вкладок в `src/components/features/movie-tracker/`, переиспользование `src/components/ui/skeleton.tsx`.
- **БД:** миграции не требуются.
- **Тесты:** unit на компоненты вкладок и скелеты; e2e на переключение вкладок и появление скелета.
- **Вне объёма:** вкладка «Статистика» группы остаётся без данных (её содержимое — существующий placeholder `EMPTY_STATS`), новые API для вкладок не добавляются.
