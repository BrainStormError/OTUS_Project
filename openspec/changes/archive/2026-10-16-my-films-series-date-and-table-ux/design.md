## Context

См. `proposal.md` — Why. Влияет на уже существующие экраны «Мои фильмы» и «Мои сериалы» и на общую форму оценки.

Текущие ограничения:

- `RatingForm.tsx` — общая форма оценки (используется в «Моих фильмах», «Моих сериалах», на главной, на странице фильма и в оценках группы). Поле даты — `<Input type="date">` без `max` и без проверки при отправке; `validateRating` проверяет только оценку.
- Дата по умолчанию берётся как `new Date().toISOString().slice(0, 10)` (`RecordModal.tsx`, `GroupRatings.tsx`) — это UTC, а не тайм-зона пользователя.
- `preferences.ts` уже даёт тайм-зону пользователя (`resolveTimeZone`, `useTimeFormat`).
- `MyFilmsView.tsx` и `MySeriesView.tsx` — почти одинаковые таблицы; раскрытая строка использует `flex items-start justify-between` с `p.min-w-0 flex-1` и `shrink-0` кнопками, без переноса длинных слов.
- Сервер (`ratings/schema.ts`) проверяет только формат даты (`^\d{4}-\d{2}-\d{2}$`), без ограничения на будущее.

## Goals / Non-Goals

**Goals:**

- Запретить дату просмотра позже текущего дня во всех формах оценки, где есть это поле.
- Считать «сегодня» в тайм-зоне пользователя и исправить UTC-дефолт.
- Удержать комментарий и кнопки раскрытой записи внутри строки таблицы на любой ширине.
- Подсвечивать весь столбец при наведении, сохранив подсветку строки.

**Non-Goals:**

- Серверная валидация «не в будущем» (граница зависит от тайм-зоны пользователя, на сервере неизвестна).
- Изменение формата или хранения `watchedAt` (дата без времени, не сдвигается тайм-зоной).
- Прочие требования к таблицам (сортировка, фильтры, статистика) не меняются.

## Decisions

**1. «Не в будущем» — на уровне формы, не сервера.**
Дата-пикер получает `max={сегодня}` (браузер не предлагает будущие даты), а отправка дополнительно проверяет дату и показывает сообщение в существующем слоте ошибки, не сохраняя запись. Серверная `.refine` отклонена: «сегодня» на сервере — это UTC, и пользователь в UTC+N, выбирающий свой локальный текущий день, получал бы ложный отказ. `max` в некоторых браузерах не мешает ручному вводу, поэтому проверка при отправке обязательна.

**2. «Сегодня» по тайм-зоне пользователя.**
Новый помощник рядом с `resolveTimeZone`/`formatTimestamp` в `preferences.ts` возвращает текущую дату `YYYY-MM-DD` в тайм-зоне (через `Intl.DateTimeFormat` с `timeZone`, ISO-подобный формат). Его используют и `max`, и проверка в форме, и дефолт даты в `RecordModal`/`GroupRatings`. Альтернатива — оставить UTC — отклонена из-за сдвига на день.

**3. Общий компонент таблицы для «Моих фильмов» и «Моих сериалов».**
Две вью почти идентичны; правки вёрстки и подсветки вносить дважды — источник расхождений. Извлекается минимальный общий презентационный компонент строки/таблицы, который держит разметку раскрытой строки и логику подсветки столбца; вью сохраняют свои `data-testid` (`my-films`, `my-series`) и логику фильтров/сортировки. Альтернатива — продублировать правки в двух файлах; отклонена.

**4. Удержание содержимого строки.**
Комментарию и заголовку добавляется перенос длинных слов (`overflow-wrap`), а контейнеру действий — перенос/укладка под комментарий (`flex-wrap`, на узких экранах — колонка). Кнопки перестают уезжать за правый край.

**5. Подсветка столбца — делегирование событий на `<table>`.**
Состояние `hoverCol` (индекс) устанавливается в `onMouseOver` по `event.target.closest('th,td')?.cellIndex`, сбрасывается в `onMouseLeave` таблицы. Ячейки и заголовок с этим индексом получают фоновый токен; строка раскрытия (`colSpan`) пропускается. Чистый CSS не может подсветить столбец таблицы; вариант с `table-fixed` по номеру столбца отклонён как хрупкий, переход на CSS-grid — как несоразмерная переработка. Подсветка декоративная: `aria` не меняется, поведение при `prefers-reduced-motion` не затрагивается (используются существующие токены переходов).

## Risks / Trade-offs

- [Ручной ввод будущей даты в браузерах, игнорирующих `max`] → проверка при отправке блокирует сохранение.
- [Пустая тайм-зона в настройках] → `resolveTimeZone` откатывается к тайм-зоне браузера, поведение остаётся корректным.
- [Состояние подсветки столбца вызывает ре-рендер при каждом наведении] → таблицы небольшие; состояние — одно число, стоимость пренебрежима. На сенсорных устройствах hover отсутствует, эффект просто не появляется.
- [Извлечение общего компонента может задеть существующие тесты] → сохраняются текущие `data-testid` и роли; тесты `series.test.tsx`, `record-feedback.test.tsx` должны остаться зелёными.

## Migration Plan

Схема данных и API не меняются — миграция не требуется. Существующие записи с прошлыми датами не затрагиваются. Откат — обычный откат кода.
